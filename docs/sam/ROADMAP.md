## 2｜已核实的基线（2026-10-22/23 本地实测）

- 纯静态 ES6 + SVG；`node scripts/validate_atlas.js` 本地 exit 0。
- 水系 `HYDRO_DATA`（`js/china_geo_data.js`）：河 187 / 湖 62 / 标签 41 条目；**其中只有 28 条带年代**（河 11 / 湖 5 / 标签 12），其余任何年份都显示。
- 黄河带年代的干流切换年：11 / 1048 / 1194 / 1855，另有支流区间 [1048,1194)、[1194,1580)；济水、淮河、泗水、废黄河、洪泽湖（1194 起）、微山湖（1560 起）、巨野泽（至 1280）、云梦泽（至 317）、罗布泊（至 1972）也带年代。**1938–1947 无独立阶段**（最后一段为 [1855, 至今)）。这些是现有代码的表达，不等于考证结论。

## 4｜数据契约要点（P0a-2 的输入）

起步只定**最少对象**，其余等有真实数据的读取方时再加（读取方定义 schema）：

| 现在定 | 以后再定（触发条件） |
|---|---|
| **Feature**：GeoJSON `type=Feature`、`id`、`geometry`、`properties`；WGS84 经度在前；原始 CRS 与转换另存 | Name 名称用例（做 P1-3 时） |
| **Source**：作者/机构、题名、版本、卷页或图号、链接、许可状态、访问日期 | Event / Relation（做人物、事件关联时） |
| **Claim（简版）**：哪条来源支持该要素的哪一项（几何／年代／名称分别支持） | Node / AccessRule / FlowObservation / Scenario（做 T1 时，按样本需要逐个加） |

字段规则：

1. **区间语义必须显式**：每个时间区间带 `interval: "half_open" | "closed"`；新数据统一半开，并给出与旧交通线闭区间的换算规则。无公元零年；保留原文纪年与规范化值；未知端点、开放端点、确定不存在三者分开。
2. **必带 `region`**（当前只有 `cn`），为同图多区域预留。
3. **对象分层 ID**：`waterbody_id`（水体）→ `segment_id`（河段）→ `geometry_id`（某次几何）→ `interpretation_id`（解释方案）→ `source_id`/`claim_id`。研究要素用 `supersedes` 指向 P0a-1 产出的 `legacy_id`。**契约 v0.1 中 GeoJSON Feature 的 `id` 即 `geometry_id`，不另设键**（R1-07 裁定）。
4. **证据方式 ≠ 置信度**：`evidence_mode`（attested / reconstructed / schematic / hypothesis）、`review_state`（流程状态）、`dating_uncertainty`、`spatial_error` 分开；没有量化依据的误差留 `null` 并写原因，不折叠成一个米数。
5. **版本**：`schema_version`、`dataset_revision`（v0.1 已有）；派生方法、审核记录推迟到 v0.2，触发条件＝P0b 出现第一条真实几何。
6. **几何规则按类型**：Polygon 查闭环/洞/自交；LineString 查最少点数、重复点、范围，不要求闭合；先支持 MultiLineString/MultiPolygon 与洞，避免导入时静默丢几何。
7. **许可分层**：来源记录、衍生几何、原图文件各有许可状态；代码 GPL 不推定数据可再分发。
8. **缺测四态**：已知不存在 / 未调查 / 无权限 / 未加载，不得都显示成"没有"。这是**覆盖层（数据集级）的显示状态**，不是单个要素的属性；要素级的 `geometry_absent_reason` 只回答"这条要素为什么没有几何"（三值）。覆盖层对象随 P0a-3 之后的版本定义。

## 5｜交通层（原 P3"交通"拆出）

研究问题："在何时、对谁、运什么、经何种通道、以什么条件可以到达"。完整规范见 Notion 模板页 I 节；这里只记执行口径：

- **T0**（第 3 项之后）：只做 `CORRIDOR_DATA` → 路段映射，补出处、方向、区间语义；不新增线路，不定义准入/流量对象。
- **T1**（待资料）：一个枢纽或有限河段、两个有证据时段，显示入流/出流、货类或用途、来源卡；地点与年代在资料审计后定，不预设替换黄河演示。
- **T2 / T3** 后置：季节、上下行、换装、准入规则过滤、枢纽迁移比较；成本/时间/风险模拟只在参数有出处时做，最短路径不等于实际历史路线。
- 编码维度：运输方式 × 用途 × 组织者 × 货类分开；**漕运是制度性用途，不与河运/海运并列为运输方式**。
- 必须通过的负例：航道存在 ≠ 特定主体/货类可通行；海禁不自动删航线或推定零流量；"明清海禁"不是两朝统一开关；"宋以前陆路、宋以后海路"只作待检验趋势；出土外来物 ≠ 直达贸易；有起讫 ≠ 知道航迹；无统计 ≠ 无贸易；资料密集 ≠ 更重要；不由往程自动补返程。
- 界面：只有可比流量才用线宽表示数量；只有联系证据时用等宽示意线。
