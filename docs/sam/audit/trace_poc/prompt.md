添付は 1938 年の日本陸軍の地図（新黄河氾濫経過要図）の一部を切り出した画像です。添付画像だけを見て、指定した線をたどり、座標列で書き出してください。

## 守ること
- シェルやファイル読み込みで画像を開こうとしないでください。リポジトリ内のファイルも読まないでください。
- 見えない部分を推測で書き足さないでください。途中で線が他の線と重なって見分けられなくなったら、そこで止めて `end_note` に書いてください。
- 座標は、画像に引いてある青い格子の数字（元の頁画像のピクセル座標）で書いてください。切り出し画像の左上は (450, 480)、右下は (1350, 1697) です。

## 凡例（この地図の線種と日付）
- 六月十二日：細かい破線
- 六月十三日夕：長い破線
- 六月十四日夕：実線（細い一本の連続線）
- 六月十五日：二本の破線の間に横線（梯子状）
- ほかに太い帯、ハッチングの帯、鉄道（目盛り付きの線）、黄河の堤（上部の二本線）があります。これらは対象ではありません。

## たどる線
図中に「14日夕」と書かれた注記が 2 つあります。
1. (850, 1130) 付近の「14日夕」— 寺台雁の北西
2. (840, 810) 付近の「14日夕」— 圃田集の北東

それぞれについて、注記が指している**実線**を一本選び、その線を両方向に端（または画像の縁、または他の線と区別できなくなる所）までたどってください。
- `vertices` は線に沿って **40 px 以内の間隔**で、線の上に乗る点を順に並べてください。曲がる所は細かく取ってください。
- 注記がどの線を指しているか決められない場合は `status` を `cannot_identify` にし、候補を `note` に書いてください。線が見えない場合は `読めない` にしてください。
- `line_style_seen` には、実際にたどった線が見た目でどんな線か（実線／破線など）を書いてください。凡例と違うと思ったらそのまま書いてください。
- 出力は指定の JSON スキーマに従ってください。
