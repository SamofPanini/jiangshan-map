# P0b-4｜东北大学「外邦図デジタルアーカイブ」核查

- 核查：Sam's Agent(Opus-5.5)，2026-10-24。线索由 Sam 提供。
- 方法：站点是 ArcGIS Hub（前端靠 JS 渲染），改用其公开 API 读取：Hub 搜索 API、页面数据（`arcgis.com/sharing/rest/content/items/<id>/data`）、图幅要素图层（FeatureServer）查询。图像查看器（OpenSeadragon）在本会话的隐藏浏览器窗格里没有加载出图块，**本轮没有目视任何一幅图像**。

## 1｜是什么

| 项目 | 内容 |
|---|---|
| 站点 | Gaihozu Digital Archives JP，https://gaihozu-jp-tohokugeo.hub.arcgis.com/ （东北大学地理学教室的外邦图收藏） |
| 图幅索引 | 要素图层 `zukaku_th`：https://services1.arcgis.com/qvPIahekAMWThrhc/arcgis/rest/services/zukaku_th/FeatureServer/0 ——**12,282 幅**，每幅一个多边形图廓（WGS84，`wkid 4326`） |
| 字段 | 编号 `ghzno`（TH……）、图名、比例尺、测量年／印刷年／发行年（缺值记 `-9999`）、地域、是否有图像、图像查看器 URL |
| 图像 | `https://nakaya-geolab.com/GaihozuTiles/?imageid=<ghzno>.jpg`（深度缩放查看器；返回 HTTP 200） |
| 站内页面 | 按地图检索、按列表检索、收藏说明、利用条款、链接集、GIS 应用 |

**对本项目的意义**：每幅图都已有经纬度图廓。按图廓**粗配准**几乎是现成的，比从零找控制点省事得多（精配准仍须控制点）。

## 3｜与黄河 1938–1947 相关的图幅（按图廓与新黄河流域大致范围 113.6–116.6°E、32.6–34.9°N 相交查询）

- 相交 **108 幅**，全部标有图像。其中 1:100,000 有 75 幅，**测量与印刷年都早于 1938**。⇒ 可作**决口前的底图**（1937 年河道）和配准控制点来源，不是泛区资料。
- 测量或印刷年落在 1938–1947 的只有 13 幅，多数是 1:200 万以下的小比例尺总图。值得目视的：

| 编号 | 图名 | 比例尺 | 年份（测量／印刷／发行） | 图廓 | 为什么看 |
|---|---|---|---|---|---|
| TH010123 | 徐州 | 1:500,000 | 1942／1926／1942 | 115.0–117.5°E、33.3–35.0°N | 1942 年修订，覆盖新黄河东段（亳州—太和一带以北）；**是否画了新河道未知** |
| TH011380 | 漢口-成都 | 1:1,000,000 | —／1942／1942 | 104.1–114.3°E | 东缘到郑州—中牟一带，可能含决口附近 |
| TH011399、TH011400 | （无图名） | 1:2,500,000 | 1942／1941／— | 未查 | 1941–42 年小比例尺，至多示意 |
| TH010143 | 開封 | 1:500,000 | —／1928／1932 | 112.5–115.0°E、33.3–35.0°N | 决口前，覆盖花园口—中牟—尉氏 |

- 按图名找「黄河」只命中 3 幅「黄河口」「舊黄河口」（1915–16 年，山东入海口）。**『新黄河流域図』NOT-FOUND in 本收藏的图名字段**——但有不少图幅图名为空，所以这只能说明按图名找不到，不能说本收藏没有。

## 5｜TH010123「徐州」1:50 万（2026-10-24 目视）

- 图廓外左侧注记（竖书）：「大正十五年製版 昭和十七年鐵道及新黄河補[入?]」「昭和十七年十一月二十五日發行」。右上：「極祕」「東亞五十万分一圖」。⇒ 这一版是在 1926 年原版上**补绘了铁道和新黄河**，1942-11-25 发行。最后一字裁图里落在图框边，读作「入」，未完全确认。
- 图面：鹿邑以南到亳州以南之间，有一条注「新黄河」的浅蓝色水线，注记在十字河附近，水线大致西北→东南走向。图上另注有「渦河」，两者分开画。水线的完整起止只在 2000 px 缩图上看过，没有逐段追踪。
- 意义：这是 1942 年的**小比例尺河道**，可作 1940 年代新黄河东段的走向参照。精度只到 1:50 万，不能代替 1:5 万『新黄河流域図』。
- 其余：该图的「图幅接合表」里列有「開封」等邻幅；TH010143「開封」是 1932 年版（决口前），所以开封幅不会画新黄河。
