- 先秦文献里的「云梦」多指楚王游猎区，含山林、原野和部分湖泊，范围很广；只有其中的湖泽部分才是「云梦泽」。汉晋注疏把「云梦」一律解成泽，作者认为是误解。
- 作者认为两汉三国人的说法最可靠：云梦泽在江陵以东、江汉之间，大致在华容县的南部和东部；杜预一系的江南（洞庭/巴丘湖）说和江北安陆说，以及清代的「跨江南北」扩大说，都被作者否定。
- 变迁：先秦以前范围更大；战国时汉水北岸一带已淤为陆；秦汉时主体仍在华容一带并随三角洲扩展东移、缩小；魏晋时东部大片被三角洲分割，「云梦泽」之名约在东晋南朝消失；南朝尚有大𬇕、马骨、太白等湖，面积已远不如前；唐宋继续缩小，宋代多为芦苇沼泽；明清后太白湖、洪湖再现。作者强调受地壳下沉和泥沙去向影响，过程不是直线的，局部有反复。

## D. 一句判断

适合作为第一批（先读、先核图，再决定能否入库）：
1. 谭其骧《云梦与云梦泽》（A3，转载页已读到完整论点；原刊为《复旦学报》1980历史地理专辑，或《谭其骧历史地理十讲》2022年中华书局版）——因为它给出整套概念区分和各时期叙述，学界后续各说多以它为参照；缺点是需到原书看图，图的许可未知。

3. 杨守敬《歷代輿地圖》《水經注圖》Commons 扫描件（B1、B2）——因为它们是本次唯一确认为公有领域且可获取的历史地图类资料；但它们是否画了云梦泽、能否配准，**必须先打开 PDF 核实**，所以只能作「待核实候选」，不要先当作底图。
